# CLARIFY Extension (Prototype)

## Load in Chrome
1. Go to chrome://extensions
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the `clarify-extension/` folder

## Use
- Click the extension icon → "Open CLARIFY Viewer"
- In viewer, click "Open PDF" to select a local PDF
